# Рэгдолл Песочница 3D

Физическая 3D-песочница с рэгдолл-человечками прямо в браузере, в духе People Playground.

**Играть:** https://counterstrike2vsco2-hash.github.io/Digger/

## Что можно делать
- ✋ **Рука**: хватать человечков и предметы, таскать и бросать (колесо мыши — ближе/дальше)
- 🧍 **Человечек**: поставить нового. Человечки держат равновесие, от сильных ударов падают и оглушаются, потом встают
- 📦 **Ящик** (с Shift — большой), 🛢️ **взрывоопасная бочка**, 💣 **бомба** с таймером на 3 секунды
- 🔫 **Пистолет** (если держать кнопку — очередь), 🚀 **базука**
- 🟦 **Батут**, 📌 **гвоздь** (прибить часть тела или предмет к месту), 🧽 **ластик**
- На арене: вышка с лестницей, пандус, стена и вращающаяся «мясорубка»

## Управление
| Клавиша | Действие |
|---|---|
| ЛКМ | инструмент |
| ПКМ + мышь | крутить камеру |
| Колесо | зум |
| WASD, Q/E, СКМ | двигать камеру |
| 1–0 | выбор инструмента |
| T | замедление времени |
| G | гравитация: Земля → Луна → невесомость |
| P | пауза физики |
| R | сброс сцены |
| Del | очистить всё |
| H | подсказка |
| Ё | счётчик FPS |
| Esc | меню |

## Для слабых ПК
В меню есть **⚡ Режим производительности**: простое освещение, без теней и сглаживания, меньше частиц.
На слабых видеокартах (R7 2xx/3xx, Vega 3–11, Intel HD/UHD и т.п.) он включается автоматически, но его можно выключить.
Разрешение не снижается, игра всегда рисует в родном разрешении экрана.
В меню также можно выключить кровь, отрыв конечностей и вставание человечков.

## Сборка
Код лежит в `src/` (three.js + cannon-es), собранный бандл — в `js/ragdoll3d.js`.
```

npm run build
```
