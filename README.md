# ДИГГЕР: Бомбарь 3D

Стелс от первого лица про диггерство. Ты — диггер, который ночью залез в заброшенное советское бомбоубежище под заводом. Собирай хабар, фоткай плакаты и гермодвери, прячься в темноте от ЧОПа и спускайся всё глубже.

▶ **Играть (3D):** https://counterstrike2vsco2-hash.github.io/Digger/
▶ Старая 2D-версия: https://counterstrike2vsco2-hash.github.io/Digger/2d/

## Управление

| ПК | Телефон | Действие |
|---|---|---|
| WASD | левая половина экрана | идти |
| мышь (клик — захват курсора) | правая половина экрана | смотреть |
| Shift | БЕГ | бег (шумно!) |
| C / Ctrl | 🧎 | присесть, красться |
| F | 🔦 | фонарь вкл/выкл |
| E / ЛКМ | 📷 | сфоткать / спуститься / вылезти |
| M | 🗺 | миникарта |
| Esc | ❚❚ | пауза |

## Что внутри

- **3D на Three.js**: фонарь с мягкими тенями, мигающие аварийные лампы, лунный луч из люка, туман, пыль, видимая в луче, объёмные лучи фонарей охраны, ACES-тонмаппинг, зерно и виньетка.
- **Все текстуры генерируются кодом**: бетон, советская стена (зелёная панель + побелка, облупленная краска, ржавые потёки), кафель, рифлёный металл, линолеум, плакаты ГО, мозаика, граффити.
- **Процедурные ярусы**: шлюз с гермодверью, ФВК с фильтрами, ДЭС с дизелем ДГА-48, медпункт, пункт управления, санузел с «чашей Генуя», склад, затопленная насосная, трубы вдоль коридоров.
- **ЧОП**: охранники патрулируют, слышат шаги, бег, плеск и крыс, у каждого шкала подозрения — ищут, гонятся, теряют след.
- **Риск/награда**: глубже — ценнее хабар и больше охраны. Вылез через люк — хабар твой, поймали — остаются только фотки.
- Три пресета графики (низкая / средняя / высокая) для слабых телефонов и мощных ПК.

## Разработка

```bash
npm install
npm run build    # собирает src/ → js/digger3d.js (esbuild, Three.js вшит в бандл)
```

Исходники: `src/main.js` (игра, рендер, ввод), `src/world.js` (3D-геометрия яруса), `src/level.js` (генерация, ИИ-пути), `src/textures.js` (процедурные текстуры), `src/audio.js` (WebAudio).
Готовый бандл `js/digger3d.js` лежит в репозитории, чтобы GitHub Pages раздавал игру без сборки.
