# ДИГГЕР: Бомбарь

Браузерная стелс-игра про диггерство. Ты — диггер, который ночью залез в заброшенное советское бомбоубежище под заводом. Собирай хабар, фоткай плакаты и гермодвери, прячься в темноте от ЧОПа и спускайся всё глубже.

▶ **Играть:** https://counterstrike2vsco2-hash.github.io/Digger/

## Управление

| ПК | Телефон | Действие |
|---|---|---|
| WASD / стрелки | джойстик слева | идти |
| мышь | — (свет туда, куда идёшь) | светить фонарём |
| Shift | БЕГ | бег (шумно!) |
| F | 🔦 | фонарь вкл/выкл |
| E / клик | 📷 | сфоткать / спуститься / вылезти |
| M | 🗺 | миникарта |
| Esc | ❚❚ | пауза |

## Механики

- **Процедурные ярусы**: каждый раз новый бомбарь — шлюз, ФВК, ДЭС, медпункт, пункт управления, санузел, склад, затопленная насосная.
- **Свет и тени**: фонарь с реальными тенями от стен, аварийные лампы мигают. Батарейки садятся, ищи «Кроны».
- **ЧОП**: охранники патрулируют с фонарями, слышат шаги, бег, плеск воды и крыс. Шкала подозрения: `?` — ищет, `!` — погоня.
- **Риск/награда**: чем глубже ярус, тем ценнее хабар и больше охраны. Вылез через люк — хабар твой. Поймали — хабар отобрали, остались только фотки.
- Звук синтезируется на лету (WebAudio), рекорд сохраняется в браузере.

Чистый HTML5 Canvas + JS, без зависимостей и сборки: `index.html`, `style.css`, `game.js`.
