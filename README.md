# РЭГДОЛЛ ЛАБ 2D

2D-песочница с тряпичными человечками в браузере, в духе People Playground. Графика, персонажи и код написаны с нуля.

**Играть:** https://counterstrike2vsco2-hash.github.io/Digger/
**3D-версия:** https://counterstrike2vsco2-hash.github.io/Digger/3d/

## Что есть
- **Человечки** собраны из 11 частей тела на шарнирах. Стоят и держат равновесие, у каждой части своё здоровье. Есть кровопотеря, боль, переломы, потеря сознания и смерть, лицо меняется по состоянию. При наведении курсора видно здоровье.
- **Оружие:** пистолет, автомат, дробовик, нож, меч, кувалда. Поднесите оружие к руке человека, и он его возьмёт. Пули пробивают насквозь, выстрел в голову смертелен. Ножи и мечи втыкаются в тела и дерево.
- **Взрывчатка:** граната с чекой, взрывпакет с таймером, бочка, которая взрывается от удара или выстрела. Взрывы вызывают цепные реакции, оставляют копоть и отрывают конечности.
- **Предметы:** ящик, доска, кирпич, мяч, наковальня, шипы (на них насаживаются), батут, стальная балка.
- **Инструменты:** рука, верёвка, сварка, заморозка, ластик, взрыв, скальпель.
- **Контекстное меню по ПКМ:** вылечить, привести в чувство, убить, развернуть, сломать кость, отрезать часть, выстрелить, выронить оружие, вытащить нож и т. д.
- Кровь брызгает, капает из ран и остаётся пятнами на полу и стенах.
- Замедление времени, пауза, гравитация (Земля, Луна, невесомость).

## Управление
| Клавиша | Действие |
|---|---|
| ЛКМ | тащить / поставить предмет из каталога |
| ПКМ | меню действий (с движением мыши — двигать камеру) |
| Колесо | масштаб |
| WASD / стрелки / СКМ | камера |
| F | выстрелить / активировать предмет под курсором |
| Q / E | вращать то, что держите |
| X | развернуть (при размещении — развернуть предмет) |
| Z | заморозить / разморозить |
| H | вылечить человека |
| Del | удалить объект под курсором |
| 1–7 | инструменты |
| Пробел | пауза |
| T | замедление |
| G | гравитация |
| Esc | меню и настройки |

## Производительность
- **Режим производительности для слабых ПК.** Включается автоматически на слабых видеокартах (Radeon R7 / Vega / Intel HD и т. п.), его можно переключить в меню. Режим уменьшает число частиц, разрешение слоя пятен и число итераций физики. **Разрешение экрана всегда полное.**
- Отрисовываются только объекты в кадре: всё за пределами экрана отсекается. Уснувшие тела не считаются физикой.
- 30 человечков и 25 предметов дают около 5 мс на шаг физики.

## Разработка
```bash
npm install
npm run build     # 2D → js/lab2d.js
npm run build:3d  # 3D → 3d/js/ragdoll3d.js
```
Исходники 2D лежат в `src/`, физика на [planck.js](https://github.com/piqnt/planck.js) (Box2D). Исходники 3D лежат в `src3d/` (three.js + cannon-es).
