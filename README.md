# РЭГДОЛЛ ЛАБ 2D

2D-песочница с тряпичными человечками в браузере, в духе People Playground. Графика, персонажи и код написаны с нуля.

**Играть:** https://counterstrike2vsco2-hash.github.io/Digger/
**3D-версия:** https://counterstrike2vsco2-hash.github.io/Digger/3d/

## Что есть
**Каталог с вкладками** (как в оригинале):
- **Манекены:** человек и жёлтый краш-манекен (без крови и сознания).
- **Холодное:** нож, меч, копьё, топор, кувалда. Остриё втыкается в тело и в дерево, рубящие удары отсекают конечности.
- **Огнестрел:** пистолет, автомат, дробовик, снайперка, лазер. Пули пробивают насквозь, есть отдача, гильзы и вспышка. Лазер прожигает и поджигает.
- **Взрывчатка:** граната, взрывпакет, бочка (взрывается от удара и от пули), коктейль Молотова (разбивается и поджигает), мина (срабатывает, если наступить).
- **Механизмы:** кнопка, таймер, ускоритель, мотор-колесо, лампа. Механизмы соединяются **проводами**: кнопка → бочка, таймер → пистолет и т. п.
- **Медицина:** шприцы «лечение», «адреналин» (не чувствует боли), «яд», «сила». Шприц втыкается в человека, и он сразу действует.
- **Предметы:** ящик, доска, кирпич, мяч, наковальня, шипы, батут, балка, бетонная стена, стул.

**Тело:**
- 11 частей на шарнирах с ограничениями углов. Человечки стоят и держат равновесие.
- У каждой части своё здоровье, есть синяки, раны, переломы, кровопотеря, боль, оглушение, потеря сознания и смерть.
- Сустав рвётся, если на него действует слишком большая сила: взрыв, падение, удар тяжёлым предметом.
- Человек в сознании корчится от боли, огня и яда.
- **Огонь:** горят люди и дерево, пламя ползёт по телу и перекидывается на соседей, части обугливаются.
- Кровь брызгает, капает из ран и культей, остаётся пятнами на полу и стенах.

**Инструменты:** рука, верёвка, пружина, сварка, провод, заморозка, ластик, огонь, взрыв, скальпель. По ПКМ открывается меню действий над объектом.

**Время:** плавное замедление на **Пробел** (звук тоже замедляется), пауза **P**, гравитация Земля / Луна / невесомость.

## Управление
| Клавиша | Действие |
|---|---|
| ЛКМ | тащить / поставить предмет из каталога |
| ПКМ | меню действий (с движением мыши — двигать камеру) |
| Колесо | масштаб |
| WASD / стрелки / СКМ | камера |
| F | активировать предмет под курсором (сигнал идёт дальше по проводам) |
| Q / E | вращать то, что держите |
| X | развернуть |
| Z | заморозить / разморозить |
| H | вылечить |
| C | поджечь |
| Del | удалить |
| 1–0 | инструменты |
| Пробел | замедление времени |
| P | пауза |
| G | гравитация |
| Tab | скрыть каталог |
| Esc | меню и настройки |

## Производительность
- **Режим производительности для слабых ПК.** Включается автоматически на слабых видеокартах (Radeon R7 / Vega / Intel HD и т. п.), его можно переключить в меню. Режим уменьшает число частиц, разрешение слоя пятен и число итераций физики. **Разрешение экрана всегда полное.**
- Отрисовываются только объекты в кадре: всё за пределами экрана отсекается. Уснувшие тела не считаются физикой.
- 30 стоящих человечков дают около 2 мс на шаг физики, хаос из 30 человечков со взрывами и огнём — около 6 мс.

## Разработка
```bash
npm install
npm run build     # 2D → js/lab2d.js
npm run build:3d  # 3D → 3d/js/ragdoll3d.js
```
Исходники 2D лежат в `src/`, физика на [planck.js](https://github.com/piqnt/planck.js) (Box2D). Исходники 3D лежат в `src3d/` (three.js + cannon-es).
